# 已知坑清单

按"症状 → 病因 → 解法"记录。遇到怪事先查这里。

## A. 环境类

### A1. `ls` / `grep` / `tail` / `head` / `dirname` 全部 `command not found`

**症状**：bash 里带管道的命令整条失败；更坑的是 `grep` 失败时返回**空输出**，看起来像"没匹配到"。

**解法**：所有文本处理改用 Python。判据：先跑 `grep --version`，报 not found 就说明它在撒谎。

```python
import os, io, re
for n in sorted(os.listdir(d)): ...
```

### A2. `rm` 时好时坏

**症状**：同一形态命令一次成功一次 `exit 127`，且文件其实没删。

**解法**：`os.remove(p)`，或删完用 `os.path.exists()` 复核。**别信 `exit 0`。**

### A3. `node` 路径会变

**症状**：昨天能跑的脚本今天 `No such file`。

**病因**：`~/.workbuddy/binaries/node/versions/22.22.2-3` 升级成了 `-6`。

**解法**：`verify.py` 里的 `find_node()` 用 glob 搜索，不要硬编码版本号。

### A4. 装不上 PyMuPDF

**症状**：`pip install pymupdf` 报 `Could not find a version`。

**解法**：用 `pypdf`（通常已预装）。它不能渲染页面，但能提取内嵌图片——扫描件的内嵌图往往就是原始分辨率。

## B. 识题类

### B1. PDF 提不出一个字

**症状**：`pypdf` 的 `extract_text()` 返回空字符串。

**病因**：纯扫描件，没有文字层。

**解法**：`page.images` 导出内嵌图，再用多模态读图。

### B2. 图上字母读反（最致命）

**症状**：公式写成 `(h₁ − h_a) + (h_b − h₂)`，但图上是 `1 → b → a → 2`。

**病因**：扫描分辨率低，`b` 的上升笔画消失后看起来像 `c`，`a`/`b` 在小字号下难分。

**解法**：
1. 放大 5–10 倍 + `autocontrast` + `UnsharpMask`
2. **用逻辑反推校验**：如果读成 `a→c→b`，那么题目问"ab、bc"就说不通了——这时必然是读错
3. 关键题（涉及 6 分以上）必须两个方向都验证

### B3. 裁剪坐标算错

**症状**：裁出来是空白或别的区域。

**病因**：按"显示尺寸"算坐标，但实际图像像素更大。

**解法**：先 `im.size` 打印真实尺寸，按比例换算；或先裁大块（整页上半），再在结果上二次定位。

## C. 代码类（JS 模板字符串）

### C1. `SyntaxError: missing ) after argument list`

**症状**：`${mx(R`...`}` 少了一个 `)`。

**解法**：脚本扫描——找所有 `${mx(R`` 开头的位置，检查闭合反引号后 4 个字符是否是 `` `) ``：

```python
j = s.find('`', m.end()+2)
if not s[j:j+4].startswith('`)'): print('缺右括号', 行号)
```

### C2. 公式全渲染错乱 / 出现 `&thinsp;`

**症状**：`\rho` 显示成 `thinsp;rho` 之类。

**病因**：在 `R\`...\`` 里写了**双反斜杠** `\\rho`。`String.raw` 会原样保留两个反斜杠，mx 把 `\\` 当成换行转义。

**解法**：批量替换 `\\` → `\`，然后跑 `verify.py` 的"双反斜杠"项确认归零。

### C3. 整页白屏，控制台 `PAPERS is not defined`

**症状**：打开 HTML 什么都没有。

**病因**：`rebuild.py` 拼数据时漏了 `const PAPERS=[];`（`data.js` 本身不含这行，它由构建脚本补）。

**解法**：模板里已写死 `const PAPERS=[];` 在 `BEGIN_DATA` 之前，替换时不要动它。

### C4. `Identifier 'R' has already been declared`

**病因**：模板的 core 里已经定义了 `R / fx / dg / TBL / AXV`，数据文件又声明了一遍。

**解法**：数据文件**只写 `PAPERS.push(...)` 和自己的 `DIAG.xxx`**，不要重复声明公共常量。

## D. 图形类

### D1. 文字超出画布右边

**症状**：图右侧的字被切掉。

**解法**：跑 `verify.py`，它按字宽估算（CJK 1.0em、小写 0.55em、大写 0.68em、`&thinsp;` 计 0）。真实案例：`x=500`、`viewBox` 宽 620、文字 13 个汉字 → 右边界 666，超了 46px。

### D2. 热力图的色阶全挤在浅色区

**病因**：`REMAT` 用"合计"列做归一化分母（24），而单卷最大值只有 9，导致最大格只有 0.37 透明度。

**解法**：`Math.max(...rows.map(r => Math.max(r[1],r[2],r[3],r[4])))`。

### D3. 相图上的点落在错的区域

**症状**：再热循环的 `b` 点画到了穹顶内部（本应是过热蒸汽）。

**解法**：对贝塞尔近似的饱和曲线做端点插值，算出给定 `y` 处的 `x`，确认点在其右/左侧。不要凭目测。

### D4. 定熵线画歪了

**检查**：定熵过程在 T–s 图上 `x` 必须相同，在 p–v 图上是有曲率的陡线。写代码时直接写 `L x,y1 L x,y2`，别用 `C`。

## E. 内容类

### E1. 同一知识点两套卷结论相反

**例**：A 卷"同 T_max、同 q₁ → 狄塞尔最高"，D 卷"同 ε、同 q₁ → 奥托最高"。

**处理**：不是矛盾，是**约束不同**。解析里必须把两个约束并列写出，并给出"看题目给的是哪个约束"的判断法。

### E2. 教材口径有分歧

**例**："比热容是过程量"（判 ×）、"没有容积变化的过程一定不对外做功"（判 ×）、"再热的目的"（干度 vs 效率）。

**处理**：给主答案 + 括号里注明另一种口径，并在交付时告知用户"这几题按老师说法可能要改"。

### E3. 查表值精度不一致

**例**：0.006 MPa 的 `h′` 有的表给 151.50、有的 151.53。

**处理**：同一份资料内统一用一张表，并在解析里注明"数据取自本卷附表"。
