# 四类题型的解析写法

目标是"用户看完能自己复现"。每类题的最低要求不同，按下面的骨架写。

---

## 一、填空题 / 选择题

**要求**：答案要短、要准；解析要解释"为什么不是别的"。

```js
{n:'5',q:'一卡诺制冷机，热源温度是冷源温度的 3 倍，则其制冷系数为 ______。',
 a:'ε = 0.5',
 sol:`<p>逆卡诺循环制冷系数只取决于两热源温度：</p>
 ${F(R`\varepsilon=\frac{T_L}{T_H-T_L}=\frac{T_L}{3T_L-T_L}=\frac12=0.5`)}
 <div class="warn"><b>注意</b>：本题"效率"指<b>制冷系数</b>，不是热效率。
 若误用 ${mx(R`\eta=1-T_L/T_H=2/3`)} 即错。</div>`}
```

**要点**：
- 一定要写"别的答案为什么错"（本题最大陷阱是把 ε 和 η 搞混）
- 选择题把 4 个选项的对错逐一交代，不要只说对的

---

## 二、判断题

**要求**：先判定，再给**反例**或**成立条件**。

```js
{n:'8',q:'系统稳定即平衡。', a:'×（错）',
 sol:`<p>稳定只要求状态不随时间变化，不要求内部<b>没有势差</b>。
 例如稳定流动的换热器中各处状态恒定，但存在温差、压差，是稳定<b>而不平衡</b>。</p>
 <p>平衡态 = 热平衡 + 力平衡 + 化学平衡，是稳定之上更强的条件。</p>`}
```

**要点**：
- 判"错"必须给**反例**，判"对"必须给**成立范围**
- 涉及"一定""必然""所有"的表述，多半是错的，但要用反例证明而不是靠语感

---

## 三、简答 / 分析题

**要求**：分点、每点一个关键词、能用图的配图。

```js
{n:'3',q:'以理想朗肯循环为例，分析提升汽轮机入口温度带来的优缺点？', s:'4 分',
 a:'优点：平均吸热温度↑ → 热效率↑，且乏汽干度↑；缺点：受金属耐高温限制',
 sol:`<p>在 T–s 图上把 1 点沿等压线向右上移到 1′：</p>
 <ol>
 <li><b>热效率提高</b>。吸热平均温度升高，${mx(R`\eta_t=1-\bar T_2/\bar T_1`)} 增大。</li>
 <li><b>乏汽干度提高</b>。膨胀线右移，<i>x</i>₂ 从 0.86 提到 0.88～0.90。</li>
 <li><b>缺点</b>：受金属耐高温强度限制，须用昂贵的奥氏体耐热钢。</li>
 </ol>`}
```

**要点**：
- 三点式：<b>变什么 → 为什么变 → 受什么限制</b>
- 每点开头加粗关键词，便于阅卷抓分
- 题干要求"作图"时**必须**配 `dg()`，光说文字拿不到作图分

---

## 四、计算题

**要求**：编号步骤 + 每步带代入数值 + 末尾交叉验算。这是分值最高、也最容易写错的一类。

```js
{n:'2',q:'压缩比为 8 的奥托循环……求最高压力温度、热效率、净功。', s:'12 分',
 a:'p₃ = 4.75 MPa，T₃ = 1771 K；η = 56.5%；w = 440 kJ/kg',
 sol:`<p>已知 ε = 8、T₁ = 298.15 K、k = 1.4、c_v = 0.718、q₁ = 780 kJ/kg。</p>
 <div class="h">① 压缩终点 2</div>
 ${F(R`T_2=T_1\varepsilon^{k-1}=298.15\times8^{0.4}=684.9\ \text{K}`)}
 <div class="h">② 定容加热终点 3</div>
 ${F(R`T_3=T_2+\frac{q_1}{c_v}=684.9+1086.4=1771\ \text{K}`)}
 <div class="h">③ 热效率</div>
 ${F(R`\eta_t=1-\frac{1}{\varepsilon^{k-1}}=56.5\%`)}
 <div class="h">④ 净功</div>
 ${F(R`w_{net}=\eta_t q_1=440.5\ \text{kJ/kg}`)}
 <div class="key"><b>交叉验算</b>：T₄ = 771.0 K，q₂ = 339.5，w = q₁ − q₂ = 440.5 ✓</div>`}
```

**骨架固定为**：

1. **列已知**（一行写完，单位齐全）
2. **①②③ 分步**，每步一个小标题 `div.h`
3. **每条公式都带代入过程**：`= 298.15 × 2.297 = 684.9`，不要只给结果
4. **末尾 `div.key` 做交叉验算**，明确写出"两条路径一致 ✓"
5. **`div.warn` 写易错点**（单位、符号约定、近似条件）

### 计算题的三条硬规矩

| 规矩 | 说明 |
|---|---|
| 保留 3 位有效数字 | 中间步骤多留一位，最后统一 |
| 单位只在结果处标 | 中间式子里不写单位，避免视觉噪音 |
| 必须双路径验算 | 例：η 用 `w/q₁` 与 `1−q₂/q₁` 各算一遍；`Π` 用 `T₀ΔS` 与 `W_max−W_net` 各算一遍 |

## 五、作图题

**要求**：SVG 必须几何自洽 + 逐点标注 + 作图要点文字。

```js
{n:'2',q:'在 p–v 和 T–s 图中画出内燃机混合加热循环，并标明循环方向。', s:'4 分',
 a:'1→2 定熵压缩、2→3 定容加热、3→4 定压加热、4→5 定熵膨胀、5→1 定容放热',
 sol:`${dg('dual','左 p–v 图，右 T–s 图；顺时针为正向循环')}
 <p><b>作图要点</b></p>
 <ol>
 <li>1→2 定熵压缩：p–v 上陡升，T–s 上是<b>竖直线</b>。</li>
 <li>2→3 定容加热：p–v 上<b>竖直线</b>，T–s 上斜率为 T/c_v 的陡曲线。</li>
 <li>3→4 定压加热：p–v 上<b>水平线</b>，T–s 上斜率 T/c_p（较缓）。</li>
 </ol>`}
```

**要点**：
- 图里每个转折点都要有字母/数字标号，且与文字步骤一一对应
- 图下必须写"作图要点"清单，说明每条线为什么长这样
- 方向（顺时针/逆时针）要画箭头，并在图注里写明

## 六、通用：什么时候用 `key` / `warn`

| 块 | 用在哪 |
|---|---|
| `div.key`（金色） | 结论、口诀、验算通过、记忆法 |
| `div.warn`（红色） | 易错点、口径分歧、近似条件的边界、符号约定 |

一篇解析里如果**通篇没有 `warn`**，大概率漏了易错点；如果**每一步都是 `warn`**，说明在替用户做决定而不是讲原理。一般每 3～5 题一个 `warn` 比较合适。
